# Base de Datos — Actividades y proyecto

Repositorio académico de la asignatura **Base de Datos (BDD)**, destinado a organizar las actividades desarrolladas durante las clases y el proyecto de diseño e implementación de una base de datos relacional.

## Organización del repositorio

| Carpeta | Descripción |
|---|---|
| [**Proyecto**](./Proyecto/) | Desarrollo de un sistema de gestión de ganado bovino de engorde. Incluye diagramas y scripts SQL. |
| [**Unidad1**](./Unidad1/) | Actividades, ejercicios y prácticas realizadas durante la primera unidad de la asignatura. |

## Proyecto — Gestion de ganado bovino

Es un proyecto enfocado en el diseño de una base de datos relacional para gestionar información del ganado bovino durante sus etapas de desarrollo y engorde.

El modelo contempla la administración de fincas, potreros, lotes de ganado, animales, historial de estancias, pesajes, alimentación, controles sanitarios, compras y ventas.

En la carpeta [Proyecto](./Proyecto/) se encuentran:

- **Diagrama Entidad-Relación:** representación conceptual de las entidades, atributos, relaciones y cardinalidades.
- **Modelo Relacional:** estructura de las tablas, claves primarias y foráneas.
- **Scripts SQL:** sentencias para la creación de tablas e inserción de datos en MySQL.

## Unidad 1 — Actividades de clase

En la carpeta [Unidad1](./Unidad1/) se recopilan las actividades y ejercicios desarrollados durante las clases, como parte del aprendizaje de los conceptos y herramientas de bases de datos.

## Herramientas utilizadas

- **MySQL:** creación y gestión de bases de datos relacionales.
- **draw.io:** elaboración de diagramas Entidad-Relación y modelos relacionales.
- **GitHub:** almacenamiento y control de versiones de los trabajos realizados.

Los diagramas pueden visualizarse y editarse desde [diagrams.net](https://app.diagrams.net/).
